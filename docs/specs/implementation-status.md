# حالة التنفيذ — 29 أكتوبر 2026

هذه نسخة تأسيسية، وليست منصة مكتملة أو جاهزة لبيانات المجموعات الحقيقية. المرجع الوظيفي decisions-ar.md. تصميم الموقع التعريفي وخط كايرو محفوظان؛ مشروع Mercurius-V2 لم يتغير.

## ما يعمل فعليًا محليًا

- طلب تجربة محفوظ في D1، ثم تهيئة مجموعة وربط حساب قائد محدد بها بواسطة مشغل المنصة. مشغل المنصة لا يملك تفاصيل المجموعة تلقائيًا.
- API محمي بهوية الاستضافة، وعزل المجموعات على الخادم. ملف تشغيل محلي يمنح هوية التطوير فقط إدارة المنصة؛ لا يدخل ضمن ترحيلات النشر.
- تكليفات متعددة وأدوار محدودة بالوحدة، وقائد قطاع يرى الفرق التابعة. تفويض مسجل بصلاحيات ونطاق ونهاية وإلغاء، دون استبدال توقيعات المعتمدين. التعيين الكامل كقائد عام إجراء مباشر للقائد العام الحالي؛ التفويض الإداري وحده لا يسمح بإنشاء قيادة عامة.
- إنشاء السنوات والقطاعات والفرق والطلائع، والتحقق من تسلسل الوحدات وتواريخ السنوات. فصل سجل الشخص عن سجل عضويته السنوية في الإنشاء الجديد عند إعداد السنوات. نقل العضوية والتجديد لم يكتملا.
- طلب فرد، بدء المقابلة/التجربة، وقرارات الكاهن والقائد العام. الاختلاف يدخل المناقشة؛ الاتفاق ينتج قبولًا أو رفضًا. تاريخ التجربة لا يحذف.
- تقديم واقعة تاريخية بدقة يوم/سنة/تقريب مع المصدر؛ اعتمادها يحتاج السكرتارية المكلفة. استقبال ملفات شهادات وواجهة الفرد لم يكملا.
- خطط عامة وقطاعات وفرق مرتبطة بالمستوى الأعلى؛ مسار اعتماد قابل للضبط، وحفظ قائمة المعتمدين عند الإرسال. كل قرار يحتاج صاحبه وتكليفه الحالي.
- إصدار جديد للخطة بلا توقيعات موروثة، مع الاحتفاظ بالنسخة السابقة؛ المصروف عبر الإصدارات يشترك في سقف واحد، فلا تعيد النسخة فتح الميزانية المصروفة.
- اجتماع تحت خطة معتمدة، حضور وتقييم مستقلان، تقرير المخطط والمنفذ، وتسجيل الأحداث في أرشيف الفرد.
- مساهمات اختيارية وصرف فعلي داخل ميزانية معتمدة، مبالغ صحيحة بالقروش، منع تجاوز النقدية والميزانية، وسجل عمليات.
- منع تكرار الأوامر، وتحديث مشروط بإصدار السجل، ورفض التعارض بدل الكتابة الصامتة فوق تعديل آخر.
- حفظ محلي للحضور/التقييم عند تعذر الشبكة والصفحة مفتوحة، ومزامنة يدوية تعيد فحص الهوية والتكليف. تعارض نفس السجل يحتفظ بالنسختين لحين المراجعة. هذا ليس دعم PWA كاملًا؛ فتح الصفحة من الصفر دون اتصال لم يتاح بعد، وسلوك الانقطاع لم يختبر بصريًا حتى الآن.

## أدلة التحقق

- 21 اختبار قواعد أعمال ناجح: العزل، النطاق، التوقيعات، التفويض وانتهاؤه، القبول المزدوج، مراجعة التاريخ، السنوات والهيكل، نسخ الخطط ومصروفاتها، المال ومنع التكرار.
- اختبار HTTP محلي: 401 لغير المسجل وتزوير رؤوس الهوية، 403 للقراءة والكتابة عبر مجموعة اختبار ثانية ولمصدر خارجي، و400 للطلب غير الصالح.
- تجربة فعلية بالمتصفح وقراءة قاعدة البيانات: مجموعة اختبار → تكليفات → فرد → خطة 150 جنيهًا بأربع توقيعات → اجتماع وحضور واجتياز → مساهمة 200 → مصروف 120 → رصيد 80 جنيهًا. جميع الأسماء بيانات اختبار محلية.
- تجربة المتصفح: واقعة سنة 1998 ظلت قيد المراجعة ثم ظهرت في الأرشيف بمصدرها بعد اعتماد السكرتارية.
- فحص TypeScript والبناء نجحا للمرحلة الأولى؛ يعادان عند تغييرات جديدة.

## غير مكتمل

## خدمات غير متصلة

واتساب والدفع والبريد وتنبيهات الأجهزة. يسجل قرار القبول حدث رسالة بحالة provider_not_configured ولا يدّعي إرسالها. لا توجد مفاتيح خدمات مضمنة أو رسائل حقيقية مرسلة.

## حدود هندسية يجب إغلاقها قبل التشغيل الحقيقي

بيانات المجموعة حاليًا مجمعة في JSON داخل D1 مع إصدار وتحديث ذري. هذا مناسب لإثبات المسار، لكنه يحتاج ترحيلًا لجداول تفصيلية وفهارس وحدود للحجم وسياسة للأرشيف قبل التوسع. جدول group_accounts دليل التهيئة الأولية فقط؛ التكليفات داخل سجل المجموعة هي مصدر صلاحيات القراءة والكتابة الحالي. لا توجد خطة ترحيل لبيانات حقيقية بعد. واجهة التشغيل أولية وظيفية وتحتاج تنظيمًا بصريًا حسب الأدوار.
